BEFORE YOU BUILD

Read how it works and the rules first. This isn't just a formality — it matters for your own safety.

How it works

  • You pick an AI provider (Anthropic/OpenAI/Google), paste in your own API key, and configure your agent's name, tools, tone, and constraints.
  • When you hit "Build Agent," your browser calls that provider's API directly — there is no HOODFACTORY server in between at all.
  • Your agent's config (name, provider, model, system prompt, etc.) is saved automatically in this browser, per wallet address, so it doesn't get lost on refresh or logout.
  • API usage is billed directly to your own provider account, based on the model and usage you generate.

User rules

  • Use your own valid, active API key. Do not use a stolen, leaked, or someone else's key.
  • You are fully responsible for the content, use, and output of any agent you build.
  • Building agents for illegal activity, fraud, spam, or anything that violates the relevant AI provider's policies is prohibited.
  • Keep your own API key confidential — don't paste it anywhere public or share it with others.

About your API key

The API key you enter is never sent to or stored on HOODFACTORY's servers. API calls go directly from your browser to the provider you choose. The key only lives temporarily in your browser's memory for the current chat session and is never saved with the agent configuration, so you will be asked to enter it again whenever you reopen a saved agent.

Liability disclaimer

HOODFACTORY functions as a tool provider, not a custodian or storage service for your API key or code/data. Agent configs are stored locally in your own browser, not on our servers — meaning we have no access to or control over them.
